# backstory

- **Kind:** session
- **Provenance:** written for the test suite (WP-021); our own material.
- **License:** same as this repository.

Four beats at a table of two players. Only Anna knows (from her character's backstory) that Aldric
learned where Mira hides the seal (t=2). Both players see Aldric steal the seal (t=3) and Mira learn
of it (t=4). The betrayal completes in Anna's lattice and in the GM's, but not in Ben's: he never saw
how Aldric got access.
