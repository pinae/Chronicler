# harbour-fire-herald

- **Kind:** media (one outlet, Harbour Herald; every statement is a claim)
- **Provenance:** written for the outlet comparison tests (WP-054); our own material, about invented people.
- **License:** same as this repository.

The same fire as `harbour-fire`, covered by a second outlet. The Herald reports the accusation
against Mayor Holt (t=1) and then that the fire brigade found no link (t=2): the `blame` narrative
gets only its first step here, while The Courier completes it.
