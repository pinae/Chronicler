# harbour-fire

- **Kind:** media (one outlet, The Courier; every statement is a claim)
- **Provenance:** written for the media tests (WP-052); our own material, about invented people.
- **License:** same as this repository.

Five passages of The Courier about a fire at old Petra's boat shed. The outlet accuses Mayor Holt
(t=1), gives him a motive (t=4), reports sympathy for Petra (t=5) and that the fishers turn
against him (t=6): the `blame` narrative, complete and attributed to The Courier. It also claims
that Petra trusted Holt (t=3), which would seed a betrayal if claims were taken as facts; they are
not, because `betrayal` has no `claimed_by` patterns.
